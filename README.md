#Style My Day
##Project Description
Style My Day is a simple Python outfit recommendation program created for my Creative Coding project at UTS. I developed this project because I am interested in fashion and wanted to make choosing outfits for different occasions easier.

##Features
-Recommends outfits for five occasions: University, Birthday, Sport, Work and Travel.
-Uses random.choice() to select an outfit.
-Avoids recommending the same outfit twice in a row.
-Displays outfit images using Pillow.
-Allows users to receive another recommendation.
-Lets users save their favourite outfits and view them at the end.

##How to Run
1.Download the Python file and the images folder.
2.Make sure Python and Pillow are installed.
3.Open the project in VS Code.
4.Run Yilin Gao.py.
5.Enter a number from 1 to 5 to choose an occasion.
6.Follow the instructions to receive recommendations and save favourites.
